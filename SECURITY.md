# Security reports

Do not report vulnerabilities with exploit details, private audio or credentials
in public issues. Use GitHub's **Security → Report a vulnerability** when enabled.
If that option is unavailable, open an issue asking a maintainer for a private
contact channel without disclosing the vulnerability. There is no guaranteed
response time or supported long-term release branch during the preview.

Include affected versions, impact, reproduction steps and a minimal example
without personal recordings. Audio processing is local; the updater contacts
GitHub for the feed and downloads. Never disable Gatekeeper or SIP to use ClearMic.
